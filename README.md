# 2026 马年职场测评 - 你是什么马？(简称 测你马)

> 2026 是马年，打工人的精神状态还好吗？来测测你是职场里的什么马！

一个有趣的 H5 测评小应用，通过回答职场相关问题，测出你是哪种"职场马"。支持生成分享图片，方便发朋友圈。

开发起因是刷抖音看到有人发类似的结果图片 但是只是PS一张图片 于是想结合测评来生成

## 预览

在线体验：[在线体验](https://sm.niceai.fun)

## 功能特点

- 15 道沙雕职场测评题
- 15 种马的测评结果
- 毒舌结果描述
- 自动生成分享图片（带圆角 PNG）
- 支持长按保存 / 点击下载
- 移动端适配

## 技术栈

- **Vue 3** - 前端框架
- **Vite** - 构建工具
- **html2canvas** - 生成分享图片

## 自定义配置

### 修改马的类型

编辑 `src/data/horses.js`，每个马包含以下字段：

```js
{
  id: 'niuma',           // 唯一标识
  name: '牛马',           // 显示名称
  description: '...',    // 毒舌描述
  shortDesc: '...',      // 短语（显示在图片上）
  attributes: {          // 属性值（0-100）
    摸鱼指数: 5,
    暴躁值: 20,
    干饭能力: 30,
    卷度: 100
  },
  color: '#8B4513'       // 主题色
}
```

### 修改题目

编辑 `src/data/questions.js`，每道题包含问题和 4 个选项，每个选项有对应的得分数组。

### 替换图片

- 马的配图：放入 `src/assets/horses/` 目录，命名为 `{马的id}.jpg`
- 二维码：放入 `src/assets/qrcode/qrcode.png`
