# 马的配图目录

请将马的配图放在这个目录下，文件名格式：`{马的id}.png`

例如：
- niuma.png（牛马）
- banma.png（班马）
- kajima.png（卡急马）
- moyuma.png（摸鱼马）
- tiaocaoma.png（跳槽马）
- tangma.png（躺马）
- fengma.png（疯马）
- juanwangma.png（卷王马）
- bailanma.png（摆烂马）
- xijingma.png（戏精马）
- yinshenma.png（隐身马）
- beiguoma.png（背锅马）

图片建议：
- 尺寸：400x400 或更大（正方形）
- 格式：PNG（支持透明背景更佳）
